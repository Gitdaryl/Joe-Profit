**Format used on every script:** Lesson delivered in full, then the book is positioned as the deeper layer, then a soft close pointing to the link in the description. The viewer gets real value whether they buy or not. That is what makes them want more.

**CTA rotation:** The soft close line is varied across all 68 (link is in the description / full story in the description / the book is in the description / grab it in the description). Keep rotating so the feed never feels templated.
